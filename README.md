# Criminal Risk Assessment Request – ODK XLSForm

## 📌 Project Overview

This project contains an ODK XLSForm developed for the **Criminal Risk Assessment Request** workflow.

The form was created based on the provided Criminal Risk Assessment Request document and is designed to organize the required information into a structured digital form.

The XLSForm was tested and validated to ensure that the form structure, questions, choices, required fields, calculations, and validation rules work correctly.

---

## 🎯 Objective

The main objective of this assignment is to convert the provided Criminal Risk Assessment Request document into a structured and functional **ODK XLSForm**.

The form is organized into different sections so that information can be entered clearly and consistently.

---

## 📋 Form Sections

The form contains the following major sections:

### 1. Authorization & Consent
This section collects the required consent-related information, including:

- Consent status
- Date of consent
- Signature of the person being assessed
- Witness information where applicable

### 2. Person Information
This section collects identifying information about the person being assessed, including:

- First name
- Second name
- Last name
- Date of birth
- Gender
- Other names used
- Current address
- Contact phone numbers
- City, province or country of birth

### 3. Identification Information
This section records the identification documents provided.

The form allows identification information such as:

- Birth Certificate
- Social Insurance Card
- Manitoba Health Card
- Treaty Card
- Other identification
- Manitoba Driver's License with photo

The form also includes validation to ensure that the required identification information is provided.

### 4. Assessment Request Details
This section collects information related to the assessment request, including:

- Person being assessed
- Requesting agency
- Reason for risk assessment
- Assigned worker
- Previous risk assessment date
- Submitting designate
- Contact phone
- Contact email
- Fax
- Request date

---

## ⚙️ XLSForm Components

The project contains the following XLSForm sheets:

### Survey
The `survey` sheet contains:

- Question types
- Internal field names
- Labels
- Required fields
- Conditional logic
- Validation rules
- Calculations
- Grouping using `begin group` and `end group`

### Choices
The `choices` sheet contains the selectable options used by the form, such as gender, identification documents, consent options, and assessment reasons.

### Settings
The `settings` sheet contains the form configuration, including:

- Form title
- Form ID
- Version
- Default language
